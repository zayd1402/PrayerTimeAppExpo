## Architecture Notes

**React Native Expo app** with a tab-based navigation structure. Five tabs: Today, Worship, Qibla & Mosques, Calendar, Learn. Uses:
- **`src/context/`**: React Context for global state (`PrayerAppContext` for app state, `ThemeContext` for light/dark/system).
- **`src/services/`**: Service modules (prayer time calculation, location, notifications, storage, audio, hijri, ramadan, sacred time, timezone).
- **`src/screens/`**: 15+ screen components, one per feature area.
- **`src/data/`**: Static data (duas, hadiths, knowledge, islamic events, mosques, manual cities, sunnah routine).
- **`src/i18n/`**: English and Arabic translations (JSON-based, no auto-key generation).
- **`src/navigation/`**: Bottom tab navigator.
- **`src/components/`**: Shared UI components (ErrorBoundary, KhushuModal).
- **`DESIGN.md`**: Full design system (warm amber/gold palette, BodoniModa + Jost typography, tonal layering).

**Storage:** `react-native-mmkv` via `src/services/StorageService.ts`.
**Notifications:** `expo-notifications` via `src/services/NotificationService.ts`.
**Audio:** `expo-av` via `src/services/AudioService.ts`.
**Background tasks:** `expo-background-fetch` + `expo-task-manager`.

## Verification Policy

Before claiming completion, agents must run the cheapest relevant verification:

1. `npx tsc --noEmit` (typecheck — always relevant for TS changes)
2. `npx eslint .` (lint — relevant for non-trivial changes)
3. Build check (`npx expo export --platform web` or similar lightweight check) if available
4. Smoke check: verify the app entry point (`App.tsx`) compiles

If verification cannot run, say exactly why.

**Note:** There is no test framework currently. TypeScript strict mode and linting serve as the primary quality gates.

## Risky Areas

- **Location services**: `expo-location` with background permissions; runtime permission handling is critical.
- **Notifications**: `expo-notifications` + `expo-background-fetch` for prayer alarms; fragile across iOS/Android.
- **Prayer time calculation**: Complex astronomical math in `src/services/PrayerService.ts` — changes can break all times.
- **Audio playback (Adhan)**: `expo-av` integration; platform-specific behavior.
- **Mobile build config**: `ios/` and `android/` directories are generated by `expo prebuild` — do not edit manually.
- **Environment config**: `app.json` contains critical Expo and native app configuration.
- **i18n**: `src/i18n/ar.json` and `src/i18n/en.json` must stay in sync.
- **Dark mode**: `src/context/ThemeContext.tsx` — dark variants of colors in `darkC` object must mirror the light palette.
- **Generated files**: `ios/`, `android/`, `node_modules/`, `.expo/`, `graphify-out/`, `graphify-out/` cache files.
