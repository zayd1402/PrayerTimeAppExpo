# Project Agent Guide

## How Agents Should Work in This Repo

Use the global OpenCode harness plus this repo-specific guide. Always read `AGENTS.md` first for project identity, commands, and risky areas.

Start every session by:
1. Checking `git status` for current branch and uncommitted changes
2. Reading `AGENTS.md` for project context
3. Running `gitnexus_impact` before editing any shared symbol

## Recommended Workflow

**Small task:**

1. `/plan <task>`
2. `/build-safe <approved plan>`
3. `/verify <task>`

**Complex task:**

1. `/explore <area>`
2. `/architect <feature>`
3. `/plan <task>`
4. `/build-safe <approved plan>`
5. `/verify <task>`
6. `/review <task>`
7. `/review-tests <task>`
8. `/review-security <task>` if relevant
9. `/review-product <task>`
10. `/fix-review <issues>` if needed
11. `/verify <task>`
12. `/pr-ready`

## Repo-Specific Gotchas

- **Do not edit `ios/` or `android/` directories** — they are generated by `expo prebuild`.
- **PrayerService.ts** uses complex astronomical math — changes here affect all prayer times. Test thoroughly.
- **i18n files** (`ar.json` / `en.json`) must stay in sync — same keys in both files.
- **Dark mode colors** in `ThemeContext.tsx` (`darkC` object) must mirror the light palette structure.
- **MMKV storage** is used via `StorageService` — never use AsyncStorage directly.
- **Animations** must use `react-native-reanimated` with `transform`/`opacity` — never layout properties.
- **DESIGN.md** is the design system authority — do not modify without explicit approval.
- **CLAUDE.md** and tooling config (`.claude/`, `.codex/`, etc.) should not be modified.

## Risky Commands

| Command | Risk | Why |
|---|---:|---|
| `npx expo run:android` | High | Full native build, requires Android SDK, 10+ minutes |
| `npx expo run:ios` | High | Full native build, requires macOS + Xcode, 10+ minutes |
| `npx expo prebuild` | Medium | Regenerates ios/ and android/, can break native config |
| `npx expo start --tunnel` | Low | Dev server with tunnel, safe |
| `npm install <package>` | Medium | Adds new dependency, needs evaluation |
| `rm -rf node_modules/` | Low | Safe but slow to reinstall |

## Safe Verification Commands

- `npx tsc --noEmit` — TypeScript type checking (~30 seconds)
- `npx eslint .` — Lint checking (~10 seconds)
- `npx expo export --platform web` — Lightweight build check (~1 minute)
