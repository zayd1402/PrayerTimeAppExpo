# Repository Map

## Overview

Cross-platform (iOS/Android) prayer time mobile application built with Expo SDK 56 + React Native. Features prayer time calculation, Qibla direction, Islamic calendar, duas, hadiths, worship tracking, and educational content. Uses a warm amber/gold design system with BodoniModa and Jost typography.

## Directory Map

| Path | Purpose | Agent Notes |
|---|---|---|
| `App.tsx` | App entry point | Sets up providers (Theme, Navigation, PrayerApp, ErrorBoundary), loads fonts |
| `src/screens/` | Screen components (15+) | One file per feature: TodayScreen, WorshipScreen, CalendarScreen, etc. |
| `src/services/` | Business logic services | PrayerService (astronomy), LocationService, NotificationService, StorageService, AudioService, etc. |
